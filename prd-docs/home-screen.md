# HomeScreen（首页）功能详细设计

## 1. 页面概述

首页是应用的入口页面，主要功能是展示用户选择的文件列表，并提供文件管理功能。

## 3. 数据模型

### 3.1 FileItem 接口

```typescript
interface FileItem {
  id: string;          // 文件唯一标识（URI）
  name: string;        // 文件名
  type: FileType;      // 文件类型
  content: string;     // 文件内容
  uri: string;         // 文件URI
  size?: number;       // 文件大小（字节）
  lastModified?: Date; // 最后修改时间
  isBookmarked?: boolean; // 是否已添加书签
}

type FileType = 'markdown' | 'text' | 'code';
```

### 3.2 文件类型判断逻辑

```
文件名后缀 → 文件类型映射
.md → markdown
.txt → text
.js/.ts/.jsx/.tsx/.py/.go/.java/.c/.cpp → code
其他 → text
```

## 4. 功能详细说明

### 4.1 文件选择功能

**触发方式**：点击“添加文件”按钮

**处理流程**：
1. 调用 `DocumentPicker.pick()` 打开系统文件选择器
2. 用户选择文件后，获取文件 URI
3. 使用 `RNFS.readFile()` 读取文件内容
4. 根据文件名判断文件类型
5. 创建 FileItem 对象并添加到状态管理
6. 自动跳转到阅读器页面

**错误处理**：
- 用户取消选择：不进行任何操作
- 文件读取失败：显示错误提示
- 文件过大（>10MB）：显示警告并拒绝加载

### 4.2 文件列表展示

**列表项信息**：
- 文件图标（根据文件类型显示不同图标）
- 文件名
- 文件大小（可选）
- 最后修改时间（可选）
- 书签状态（可选）

**交互功能**：
- 点击文件项：打开文件并跳转到阅读器
- 长按文件项：弹出操作菜单（删除、重命名、分享）
- 左滑文件项：显示删除按钮

### 4.3 文件管理功能

**删除文件**：
1. 从状态管理中移除文件记录
2. 注意：不会删除原始文件，只移除应用内的记录

**重命名文件**：
1. 弹出输入框，显示当前文件名
2. 用户输入新名称
3. 更新状态管理中的文件记录

**分享文件**：
1. 调用系统分享功能
2. 分享文件内容或文件本身

## 5. 数据运转流程

### 5.1 文件选择流程

```
用户点击“添加文件”
    ↓
DocumentPicker.pick() 打开系统文件选择器
    ↓
用户选择文件 → 返回文件 URI
    ↓
RNFS.readFile(uri, 'utf8') 读取文件内容
    ↓
getFileType(fileName) 判断文件类型
    ↓
创建 FileItem 对象
    ↓
store.addFile(fileItem) 添加到状态管理
    ↓
store.setCurrentFile(fileItem) 设置当前文件
    ↓
navigation.navigate('Reader') 跳转到阅读器
```

### 5.2 文件列表加载流程

```
应用启动
    ↓
从状态管理获取 files 数组
    ↓
渲染文件列表
    ↓
监听状态变化，实时更新列表
```

### 5.3 文件删除流程

```
用户长按文件项
    ↓
弹出操作菜单，选择“删除”
    ↓
显示确认对话框
    ↓
用户确认删除
    ↓
store.removeFile(fileId) 从状态管理移除
    ↓
更新文件列表显示
```

## 7. 样式设计

### 7.1 颜色主题

**浅色主题**：
- 背景色：#FFFFFF
- 主色调：#007AFF

- 次要文字色：#666666
- 分割线色：#E5E5E5

**深色主题**：
- 背景色：#121212
- 主色调：#0A84FF

- 次要文字色：#999999

### 7.2 尺寸规范

- 列表项高度：72px
- 头部高度：56px
- 内边距：16px
- 列表项间距：8px

## 8. 性能优化

### 8.1 列表虚拟化

当文件数量较多时，使用 `FlatList` 进行虚拟化渲染，只渲染可视区域内的列表项。

### 8.2 图片懒加载

如果文件列表包含预览图，使用懒加载策略，避免一次性加载所有图片。

## 9. 无障碍设计

- 所有按钮添加 `accessibilityLabel`
- 列表项添加 `accessibilityRole="button"`
- 支持屏幕阅读器导航
- 颜色对比度符合 WCAG 标准
