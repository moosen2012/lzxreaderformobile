1. 断点与布局档位

从「宽/窄两档」升级为四档，再叠加方向修正。宽度决定结构，高度决定密度。

# 架构设计

260　│　320　│　flex（正文 max-width 780 居中）
  • ① 树只显示目录，列表显示当前目录内容，右栏显示选中文件
  • ② 点文件不切走列表 —— 这是和现状「右栏替换」最大的差别，连续翻阅不用来回退回
  • ③ 未选文件时右栏是占位（「从左侧选择一个文件」），不抢占列表宽度
  • ④ 正文 max-width:780；平板横屏不加限制会长到 100+ 字符/行
